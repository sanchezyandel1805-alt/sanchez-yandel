# 1. ¿Qué es la seguridad informática y cuál es su importancia?
# Es la protección de las computadoras, los dispositivos y la información contra robos, virus y ataques. Es importante porque ayuda a mantener nuestros datos seguros y privados.
# 2. ¿Qué significan los principios de confidencialidad, integridad y disponibilidad?
# La confidencialidad significa que solo las personas autorizadas pueden ver la información. La integridad evita que los datos sean modificados sin permiso y la disponibilidad permite acceder a ellos cuando los necesitamos.
# 3. ¿Cuál es la diferencia entre virus, malware y ransomware?
# Un virus es un programa que puede infectar una computadora. Malware es el nombre general de los programas maliciosos y ransomware es un tipo de malware que bloquea archivos y pide dinero para recuperarlos.
# 4. ¿Qué es el phishing? ¿Cómo podemos reconocerlo?
# Es una forma de engaño en la que alguien se hace pasar por una empresa o persona conocida para robar nuestros datos. Podemos reconocerlo por mensajes sospechosos, enlaces extraños o pedidos de contraseñas.
# 5. ¿Qué es la ingeniería social?
# Es una técnica que utilizan los delincuentes para engañar a las personas y conseguir información privada. Por ejemplo, pueden hacerse pasar por empleados de un banco para pedirnos datos personales.
# 6¿Qué características debe tener una contraseña segura?
# Debe ser larga y combinar letras, números y símbolos. También es importante que no tenga datos personales y que sea diferente para cada cuenta.
# 7. ¿Qué diferencia existe entre un hacker White Hat y un Black Hat?
# El White Hat es un hacker ético que utiliza sus conocimientos para encontrar errores y mejorar la seguridad. El Black Hat utiliza sus conocimientos para robar información, entrar sin permiso o causar daños.
# 8. ¿Por qué es importante realizar copias de seguridad?
# Porque nos permiten recuperar nuestros archivos si se borran, se dañan o perdemos el dispositivo. Así evitamos perder información importante.
